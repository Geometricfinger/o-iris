# ADR-0018: Voice (D-18)

- Status: Accepted (settled default, spec v2). For the M-17 voice link only, "no ambient audio" and "liveness-consistency purpose only" are superseded by ADR-0057 (2026-11-16). Everything else here still applies.
- Date: 2026-10-28
- Source: docs/spec/ASB-Build-Spec-v2.pdf, section 15

## Decision

Push-to-talk, hardware mute, no ambient audio, no audio files; embeddings ephemeral unless written enrollment; liveness-consistency purpose only.

## Where it is enforced

oiris/guard/privacy.py (no audio), oiris/scores/builtin.VoiceScore

## Changing it

Write a new ADR that supersedes this one, update CHANGELOG.md, and (if it touches a guardrail) get owner sign-off. A change to a frozen test threshold cannot be used to declare a pass retroactively.
