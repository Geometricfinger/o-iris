# oiris.features — signal processing
Pure functions (NumPy only): `optical` (A1/A2), `thermal` (A3 + M-08 rendering), `eye` (M-01, hypothesis), `vital` (rPPG POS, band SNR), `rf` (M-03), `baseline` (M-07). **Inputs**: arrays. **Outputs**: numbers/dicts. **Depends on**: numpy. No I/O, no state except the drift detector. Add new functions with a synthetic-signal test.

`eye_roi.py`: live eye ROI finding (dark pupil + LED-following glint, or face landmarks) and `EyeTracker`, which produces the `eye` sample from LED-coded NIR frame pairs (ADR-0051).

`doa.py` (360-degree coverage plan): sound direction of arrival. `gcc_phat` gives a mic pair's time difference (s, positive when mic b hears it after mic a) and a confidence, searching only physically possible lags (spacing / 343 m/s); `doa(channels, mic_positions_m, sample_rate)` fits all pairs as a far-field plane wave and returns `DoaResult(az_deg, el_deg, ambiguous, candidates, confidence, pairs_used)` in the shared head frame (ADR-0060: x forward, y left, z up; az +90 = left), ready to become a spatial detection of kind "sound", family "voice"; `direction_of_bearing` maps a bearing to the phrase words (ahead/at left/at right/behind/above/below, 10 deg hysteresis). Geometry limits are reported, never guessed: one pair (e.g. one mic per temple) gives left/right but not front/back (`ambiguous=True`, both candidates, source assumed near the horizontal plane); a horizontal planar array gives full azimuth but no elevation; a tilted/vertical plane is mirror-ambiguous; only non-coplanar mics give elevation; silence, uncorrelated noise or weak peaks return `None`. Regularised PHAT (floor = mean cross-spectrum magnitude) so harmonic voices work; harmonic tones at 10 dB SNR mostly return `None`. Proven on synthetic signals only (`tests/test_doa.py`); not modelled: head shadow/diffraction, near-field sources, real reverberation, mic gain/phase/clock mismatch, several simultaneous talkers.

`aruco.py` (M-07): numpy-only ArUco DICT_4X4_50 detector + planar pose; `baseline.register_anchors` / `anchor_in_view` / `pass_from_view` key site baselines by detected marker ID. `eye_recordings.py` (M-01): loads real eye-tracker recordings (Tobii/LaborTrack format, generic CSV) and scores `eye.blinks()` against reference events (`tests/test_eye_real.py`). `rf_tables.json` (M-03): Bluetooth SIG company IDs and IEEE camera-maker OUIs, regenerated by `scripts/make_rf_tables.py`.
