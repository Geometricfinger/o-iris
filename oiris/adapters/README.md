# oiris.adapters — sensor port (C2, M-11)
**Purpose**: turn hardware, recordings or generators into `Sample`s. **Inputs**: device / file / seed. **Outputs**: `Sample{adapter_id, t_mono_ns, t_wall, seq, units, quality, data}`. **Depends on**: `oiris.schema`, `oiris.guard.radio` (radio drivers). **Variants**: `drivers.py` (real, lazy imports), `macos.py` (`wifi_macos`, reading the O Iris.app launcher's Wi-Fi feed, and the Bluetooth permission gate used by `ble_scan` on macOS), `base.ReplayAdapter`, `sim.make()`. Live mode (`oiris run`, docs/LIVE.md) resolves these by name from the registry. `ble_scan` and `wifi_macos` do not run through `oiris.guard.radio`'s command check; `wifi_beacons` (`iw`) does.
**Extend**: see docs/EXTENDING.md "Add a sensor". The bus provides threading, timeouts, restarts and breakers; adapters stay simple.
